# JAN BROTHERS RESTAURANT

A modern and responsive restaurant website built for Jan Brothers Restaurant.

The website presents traditional Afghan food, restaurant information, food gallery, contact form, dark mode, responsive navigation, scroll animations, and WhatsApp food ordering.

## Project Overview

JAN BROTHERS RESTAURANT is a frontend web project designed to provide customers with a simple and attractive way to explore the restaurant and its menu.

The project focuses on:

- Responsive web design
- Clean HTML structure
- Modern CSS styling
- JavaScript interactions
- Dynamic menu rendering
- Contact form validation
- Dark and light mode
- Mobile navigation
- Scroll animations
- Active navigation links
- Back to top functionality
- WhatsApp food ordering
- Loading spinner
- Basic SEO metadata

## Features

### 1. Responsive Design

The website works on:

- Desktop
- Laptop
- Tablet
- Mobile devices

The navigation menu changes to a mobile menu on smaller screens.

### 2. Navigation Bar

The navigation includes:

- Home
- Menu
- About
- Gallery
- Contact

The active navigation link changes automatically when the user scrolls through different sections.

### 3. Hero Section

The hero section introduces the restaurant with:

- Restaurant name
- Short description
- View Menu button

The View Menu button takes the user directly to the menu section.

### 4. Dynamic Menu

Menu items are stored inside a JavaScript array.

Each food item contains:

- Name
- Description
- Price
- Image

Example:

```javascript
{
  name: "Afghan Kebab",
  description: "Delicious grilled kebab with traditional spices.",
  price: "100AF",
  image: "images/kebab.jpg"
}
```
